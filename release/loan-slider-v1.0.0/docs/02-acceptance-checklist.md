# 验收清单 · 贷款参数滑块组件 v1.0.0

> 验收方式：把 `dist/demo.html` 直接**双击用浏览器打开**（或拖进 Chrome / Edge 窗口）即可试用，不需要装任何环境、不需要起本地服务器。

---

## 一、30 秒快速验收

1. 双击 `dist/demo.html`，浏览打开，应看到深色卡面 + 三个可拖动滑块
2. 拖动「贷款金额」滑块 → 顶部月供数字应**实时变化**，且不卡顿、不跳动
3. 拖动「贷款期限」从 20 年拉到 30 年 → 月供应该**变小**，但「总利息」应该**变大**
4. 下方「本金 / 利息」比例条 → 期限拉长时橙色（利息）段应明显变长
5. 按 F12 打开控制台 → 拖动时应持续打印 `[loan-change]` 日志

以上 5 条都通过，说明组件核心功能正常。

## 三、数值准确性验收（关键）

拖动滑块到下表参数，核对三个数字。**允许 ±0.01 的四舍五入误差**。

| 贷款金额 | 年利率 | 期限 | 月供 | 总还款 | 总利息 |
|---|---|---|---|---|---|
| ¥300,000 | 4.20% | 20 年 | **1,849.71** | **443,930.93** | **143,930.93** |
| ¥1,000,000 | 3.85% | 30 年 | **4,688.08** | **1,687,709.64** | **687,709.64** |
| ¥500,000 | 5.50% | 10 年 | **5,426.31** | **651,157.67** | **151,157.67** |
| ¥2,000,000 | 4.90% | 25 年 | **11,575.57** | **3,472,671.67** | **1,472,671.67** |
| ¥100,000 | 3.50% | 5 年 | **1,819.17** | **109,150.47** | **9,150.47** |
| ¥800,000 | 6.15% | 15 年 | **6,815.86** | **1,226,854.35** | **426,854.35** |

**计算口径**：等额本息（银行按揭标准算法）

```
月利率 r = 年利率 ÷ 12
月供 = P × r × (1+r)^n ÷ ((1+r)^n − 1)      n = 期限(年) × 12
总还款 = 月供 × n
总利息 = 总还款 − P
```

以上结果可与各家银行官网的「房贷计算器」逐项交叉验证。

**免手动拖动的核对方式**（技术人员用）：浏览器控制台执行

```js
const el = document.querySelector('loan-calculator');
el.values = { amount: 1000000, rate: 3.85, years: 30 };
el.result;   // 直接读计算结果
```

## 四、视觉验收

| 项 | 标准 |
|---|---|
| 主色 | 薄荷绿（默认 `#5fe8c6`），与设计稿一致 |
| 滑块进度 | 已拖过的部分为绿→黄绿渐变，未拖部分为半透明灰 |
| 层级 | 月供最突出 → 总还款/总利息次之 → 滑块标签再次之 |
| 圆角 | 卡片 28px / 次级卡片 22px / 按钮 17px |
| 深色适配 | 背景 `#0b0b0d`，无生硬的纯黑或纯灰 |

如需调整任意配色，见《集成指南》第五节，**不需要改组件代码**。
