# 版本说明

## v1.0.0 — 2026-10-26

### 本次交付内容

贷款参数滑块组件首个交付版本。拖动「贷款金额 / 年利率 / 贷款期限」三个滑块，实时计算月供、总还款、总利息。

**功能**

- 三个独立滑块，带实时数值气泡、刻度区间标注、拖拽态反馈
- 实时联动：月供大数字、总还款、总利息、本金利息占比条
- 本金 / 利息构成可视化（比例条 + 百分比）
- 键盘可操作（← → 键微调），焦点态可见
- 支持深色主题，配色可通过 CSS 变量整体替换
- 移动端优先，适配 320px ~ 440px 宽度

**技术规格**

| 项 | 说明 |
|---|---|
| 形态 | Web Component（自定义元素 `<loan-calculator>`） |
| 依赖 | 无。原生 JS + CSS，不依赖框架、不需要构建 |
| 体积 | 单个 `.js` 文件约 20KB（未压缩） |
| 样式隔离 | Shadow DOM，与宿主页面 CSS 互不影响 |
| 计算方式 | 等额本息，纯前端计算 |
| 数据安全 | 组件不发起任何网络请求，不存储任何数据 |
| 浏览器要求 | Chrome / Edge 67+、Safari 12.2+、Android WebView 67+ |

### 已知限制

1. **仅支持等额本息**。等额本金需另加计算分支与切换控件。
2. 「立即申请」按钮只派发点击事件，**不包含跳转逻辑**，由宿主 App 接管。
3. iOS / Android 真机环境未实机验证，建议在目标机型上过一遍（详见验收清单第五节）。
4. 组件自带深色主题。如需浅色版，需另行适配。
